# LUMA Hair Studio

Site vitrine du salon (HTML/CSS/JS statique, hébreu + anglais).

- `index.html` : le site complet
- `img/` : photos avant / après
- `agenda/` : script Google Apps Script pour envoyer les réservations dans Google Agenda (voir `agenda/GUIDE.md`)

Déploiement : Vercel publie la branche `main` automatiquement.
